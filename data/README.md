# Data

This folder contains scenario results, landowner analysis, and subwatershed characteristics used to generate all figures in the manuscript.

## Files

**Results-scenario-landowner-subwatershed.xlsx**
- `Scenario_results` — bank erosion (T/yr) under each of the 12 management alternatives for all 15 subwatersheds
- `Strategy_eval_table` — strategy evaluation table (Table 2 in manuscript)
- `Landowner_analysis` / `Landowner_analysis_Feb_23` — erosion results stratified by landowner
- `Landowner_analysis_Feb_23_figs` — data underlying Figure 7 (cumulative benefit curves)
- `Subwatershed_analysis` — subwatershed-level scenario results
- `Subwatershed characteristics` — watershed area, stream length, precipitation, and erosion metrics (Table S5)
- `Condensed_table` — summary table
- `baseline_values` — baseline erosion values underlying the cumulative benefit curves (Figure 7)
