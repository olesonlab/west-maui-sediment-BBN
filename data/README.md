# Data

Scenario results, landowner analysis, and subwatershed characteristics used to generate the manuscript figures and tables. The scripts in `code/` read this workbook directly.

## Files

**Results-scenario-landowner-subwatershed.xlsx**
- `Scenario_results`: bank erosion (tonnes/yr), % change, and cells treated under each of the 12 management alternatives (source for Table 2 and its cost-effectiveness ratios)
- `Strategy_eval_table`: strategy evaluation table (Table 2 in manuscript)
- `Landowner_analysis` / `Landowner_analysis_Feb_23` / `Landowner_analysis_Feb_23_figs`: erosion results stratified by landowner (Figure 6)
- `Subwatershed_analysis`: subwatershed-level scenario results (Figure 5)
- `Subwatershed characteristics`: USGS sediment budget, modeled erosion, susceptibility, disturbance cell counts, area and precipitation (Table S5; source for Figures S1-S3)
- `Condensed_table`: summary table
- `baseline_values`: cell-level baseline erosion and cumulative coverage by threshold, overall and by landowner (source for Figure 7, columns E-K, rows 3-14)

Sheet names using 2_ and 9_ correspond to the manuscript's VH_ and H_ alternatives (highest 2% and 9% erosion cells).
