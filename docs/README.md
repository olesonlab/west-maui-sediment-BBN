# Supplementary Information

This folder contains the supplementary information document submitted alongside the manuscript.

## Files

**SupplementaryInformation.docx** — includes:
- **Table S1**: Model inputs and sources
- **Table S2**: Conditional probability table (CPT) for bank erosion under each combination of input variable states
- **Table S3**: Model calibration across the 15 West Maui subwatersheds
- **Table S4**: Breakpoint bin ranges for input variables
- **Table S5**: Subwatershed characteristics (area, stream length, precipitation, erosion)
- **Figure S1**: Calibration curves (ephemeral and perennial-intermittent)
- **Figure S2**: Modeled bank erosion vs. watershed characteristics, perennial-intermittent watersheds
- **Figure S3**: Modeled bank erosion vs. watershed characteristics, ephemeral watersheds
- Supplementary methods: data processing and stream flow force calculations
